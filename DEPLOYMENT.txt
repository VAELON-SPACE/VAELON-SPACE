VAELON.SPACE ENTITY / SEARCH IMPLEMENTATION

Replace the site root index.html and company.html with the versions in this package.
Add press.html, robots.txt, and sitemap.xml to the same site root.

Do NOT merge vaelon.space with vaelonspace.com. This package intentionally treats vaelon.space as its own entity.

Keep the existing /assets/ directory and existing program pages in the live project. The new HTML references the site's existing assets.

After deployment:
1. Verify https://vaelon.space/ returns 200.
2. Verify https://vaelon.space/company.html returns 200.
3. Verify https://vaelon.space/press.html returns 200.
4. Verify https://vaelon.space/robots.txt exposes the sitemap.
5. Verify https://vaelon.space/sitemap.xml returns the listed URLs.
6. In Google Search Console, inspect the homepage, company.html, press.html, and submit sitemap.xml.
