ResQNet

Risk-Aware Emergency Routing Engine

ResQNet is a graph-based routing system built for disaster and emergency response. It models the road and incident network as a weighted graph, then routes ambulances, rescue teams and evacuation flows using risk-weighted shortest-path and max-flow algorithms — so routing decisions account for live hazard conditions, not just distance.

SEC 06 / What It Does

What ResQNet does

A routing and allocation engine purpose-built for the constraints of a real emergency response, not a generic mapping API.

Routing

Risk-weighted shortest path

Dijkstra-based routing where edge cost reflects live hazard and risk data alongside distance and travel time, not distance alone.

Allocation

Max-flow resource allocation

Models ambulances, rescue teams, helicopters and shelters as distinct constrained resource types across the network as a flow problem.

Simulation

Scenario simulation

Runs disaster scenarios against the graph to evaluate how routing and capacity respond before an event occurs.

Data

Live data feeds

Ingests live incident, hazard and network-condition data so routing decisions stay current as a situation develops.

Model

Graph-based network core

The underlying road and incident network is represented as a weighted graph designed specifically for emergency-response routing.

Validation

Historical backtesting

Routing performance is evaluated against real historical disaster events, including a Tubbs Fire backtest.
